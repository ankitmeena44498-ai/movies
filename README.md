# AutoFilter Bot (Railway Deployment)

## 🚀 Deploy on Railway

1. Fork this repo or upload it to your GitHub.
2. Go to [Railway.app](https://railway.app) and create a new project.
3. Select "Deploy from GitHub Repo".
4. Add Environment Variables in Railway settings:
   - `BOT_TOKEN` → Your bot token from BotFather
   - `LOG_CHANNEL` → Your log channel ID (like `-100xxxxxxxxxx`)
5. Deploy and your bot will be online 24/7 🚀

## Commands
- `/start` → Start the bot
- Upload a file → It will be saved in DB
- Type any text in group → Bot searches and returns results
